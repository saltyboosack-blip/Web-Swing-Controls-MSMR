# Native payload staging

`build-addon.ps1` places the locally built host-gated `scripts_proxy.dll` here
before publishing the Modding Tool add-on. The binary is deliberately not
stored in the source tree.

Required SHA-256:

`FFB6AD902798D7DF87F6D3FDE3B5A4BAE1E9212A40971B346452A5064768E111`

Build the payload from the repository's `ScriptsProxy/` source first.
